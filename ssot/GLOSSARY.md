# GLOSSARY

Unambiguous definitions. Where a term is used loosely in the community, the definition here is the one this project uses.

## Elite Dangerous — game

| Term | Definition |
|---|---|
| **CMDR** | Commander. A player character. Always rendered "CMDR <Name>" in UI. |
| **BGS** | Background Simulation. The persistent simulation governing minor-faction influence, states and control of systems. |
| **Tick** | The daily BGS recalculation, roughly but not exactly the same UTC time each day. All influence deltas are measured tick-to-tick, never wall-clock. |
| **Minor faction** | An in-game faction that can control systems. A *player minor faction* is one submitted by a squadron. Grim's Squad runs one (`tracked_factions.is_ours = true`). |
| **Influence** | A minor faction's share in a system, 0.0–1.0. The primary BGS metric. |
| **State** | A minor faction condition: Boom, Bust, War, Election, Expansion, Retreat, Famine, Outbreak, Lockdown, Civil Unrest, Investment. Has `active`, `pending` and `recovering` forms — kept as separate columns. |
| **Conflict** | War or Election between two factions in a system, resolved by day-by-day win counts. |
| **Powerplay** | The separate galactic-power layer (pledges, merits, fortification, undermining). Distinct from BGS. Out of scope until P9. |
| **Fleet carrier** | A player-owned mobile capital ship with a callsign like `K7Q-B4X`, its own market, and a tritium-fuelled jump drive. Appears in market data as a station with `is_carrier = true`. |
| **Tritium** | The commodity that fuels fleet-carrier jumps. The reason the carrier fuel tracker exists. |
| **Ly / Ls** | Light years (between systems) / light seconds (from a system's arrival point to a station). Both matter: a route can be 20 ly and still be terrible at 200,000 Ls. |
| **Landing pad** | Small / Medium / Large. Stored as `SMALLINT` 1/2/3. A large ship cannot dock at a station whose max pad is smaller. |
| **Rebuy** | The insurance cost to recover a destroyed ship. A build stat members care about. |
| **Engineering** | Post-purchase module modification requiring unlocked engineers and materials. Gates most competitive builds. |
| **AX** | Anti-Xeno. Combat against Thargoids. |
| **CZ** | Conflict Zone. Combat instance generated by a system's War state. |
| **CG** | Community Goal. A time-limited galaxy-wide objective with tiered rewards. |
| **Hotspot** | A ring region with elevated spawn rate for a mining commodity. Overlapping hotspots are squadron knowledge worth curating. |
| **GalNet** | The in-universe news feed published by Frontier as JSON. |
| **Journal** | The newline-delimited JSON event log the game writes locally. The source of all telemetry. |
| **Loadout (event)** | The journal event describing a ship's complete current fit. The canonical build format we import. |

## Elite Dangerous — third-party ecosystem

| Term | Definition | Trust tier |
|---|---|---|
| **EDDN** | Elite Dangerous Data Network. ZeroMQ pub/sub relay at `tcp://eddn.edcd.io:9500` carrying zlib-compressed, player-submitted journal events. Our own data layer. | authoritative (for what it carries) |
| **EDCD** | Elite Dangerous Community Developers. The org behind EDDN, EDMC, FDevIDs, Coriolis. | — |
| **EDMC** | EDMarketConnector. The desktop client most members already run; reads the journal and forwards to EDDN. We ship a plugin for it. | — |
| **FDevIDs** | EDCD's canonical mapping from Frontier's internal names to display names for commodities, modules and ships. **The** naming authority. Never hand-map. | authoritative |
| **cAPI** | Frontier's Companion API. OAuth2 + PKCE. The only cryptographic proof that a session owns a given CMDR. Refresh tokens die at ~25 days; expiry surfaces as HTTP 422. | authoritative |
| **Ardent Insight** | `api.ardent-insight.com`. Anonymous, keyless trade/system API built on EDDN. AGPL-3.0, self-hostable, publishes dumps. | authoritative (acceleration) |
| **Spansh** | Async job-based route planners (neutron, galaxy, carrier, Road to Riches, tourist) plus nightly galaxy dumps. Submit → poll, never blocking. | best-effort |
| **EDSM** | Elite Dangerous Star Map. System coordinates, bodies, traffic and death stats. Free, no key for most endpoints. | enrichment |
| **Inara** | Community site with a JSON-POST API. **No OAuth, no login delegation.** Requires per-app whitelisting; ~2 req/min. Nightly cross-check only. | enrichment |
| **Coriolis** | MIT-licensed outfitting tool (`EDCD/coriolis` + `EDCD/coriolis-data`). Self-hosted at `shipyard.<domain>`. Code is MIT; the game data and imagery are Frontier's, non-commercial use only. | — |
| **EDSY** | `edsy.org`. The other major outfitting tool, with very compact share URLs. We import its format. | — |
| **BGS-Tally** | An existing EDMC plugin tracking BGS/Powerplay activity. We support importing its data. | best-effort |
| **EDDB** | **Dead.** Shut down in 2023. Any reference to `eddb.io/api` is stale and must not be built on. | ✗ |

## This project

| Term | Definition |
|---|---|
| **Ring 0 / 1 / 2** | Concentric access tiers. Ring 0 = public. Ring 1 = verified member. Ring 2 = officer/leadership. A "ring" is a shorthand for a permission threshold, never itself a stored value — permissions are the mechanism (see `02-domain/rings-and-roles.md`). |
| **Permission mask** | A `bigint` bitmask of `Permission` constants. Effective mask = OR(role masks) AND NOT deny mask. Stored as `NUMERIC(40,0)` because it exceeds 64 bits (ADR-005). |
| **Deny mask** | Per-user explicit revocations, subtracted last. Deny always beats grant. |
| **Internal role** | One of `guest`, `applicant`, `member`, `wing_lead`, `officer`, `commander`, `sysadmin`. A named bundle of permissions. |
| **Orthogonal tag** | A non-hierarchical role (`bgs_team`, `carrier_owner`, `miner`, `combat_wing`, `explorer`) granting specific permissions and driving notification routing. Does not imply rank. |
| **Trust tier** | How strongly a CMDR claim is proven. 3 = Frontier cAPI, 2 = Inara nonce, 1 = officer manual. Recorded per verification, never inferred. |
| **GSAI** | Grim's Squad AI. The locally-hosted Ollama agent. |
| **Instance A / GSAI-INTERACTIVE** | Ollama on the RTX 3060, port 11434, resident 24/7, serves every live request. |
| **Instance B / GSAI-HEAVY** | Ollama on the RTX 5070 Ti, port 11435, arbiter-gated, yields to the game. Batch and overnight work. |
| **Arbiter** | The service deciding whether instance B may be used, based on game process detection, free VRAM and GPU temperature. |
| **Fast path** | The deterministic, no-LLM route: embedding-similarity intent classification → direct tool call → templated response. The front door; the agent loop is the fallback (ADR-012). |
| **Agent loop** | Plan → tool-call → observe, bounded by `MAX_STEPS`. Tools are permission-filtered before the model sees them. |
| **Tool registry** | `06-ai/tools.yaml` — the authoritative list of what GSAI can do, with permission, mutating flag and confirmation requirement. Generates code. |
| **Data freshness / `dataAgeHours`** | Hours since the underlying observation. Mandatory on every market-derived value surfaced to a human or a model (INV-004). |
| **Device token** | A per-member, individually revocable bearer token scoped to `telemetry:write`, issued from the profile page for the EDMC plugin. Never a password. |
| **Doctrine build** | An officer-approved standard loadout for a role (`loadouts.is_doctrine = true`). |
| **Op** | A scheduled squadron operation with signups, roles and capacity. |
| **AAR** | After-action report. A forum thread auto-created post-op. |
| **Risk tier** | 1/2/3 classification of a change, setting which review gates are required and whether autonomous merge is allowed (`10-quality/git-workflow.md`). |
| **Review gate** | An adversarial review panel (DESIGN-ADV, ARCH-ADV, RED-TEAM, DATA-INTEGRITY-ADV, UX-ADV, OPS-ADV) that must pass before merge (`10-quality/adversarial-reviews.md`). |
| **SSOT drift** | Any divergence between a `ssot/` source file and its generated counterpart in the codebase. A CI failure, never a warning. |
